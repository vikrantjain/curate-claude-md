# curate-claude-md

A Claude Code plugin with skills for creating, updating, and trimming `CLAUDE.md` files.

## What it does

`CLAUDE.md` is meant to be a briefing read before every action, not a log of what happened.
This plugin's `curate-claude-md` skill gives Claude a concrete rule set for deciding what
belongs in a `CLAUDE.md` versus a README, a doc, or a skill, and for auditing an existing file
back down to that standard.

See [`skills/curate-claude-md/SKILL.md`](skills/curate-claude-md/SKILL.md) for the full rules.

## Installation

Add this repository as a plugin source in Claude Code, then install the `curate-claude-md` plugin.
